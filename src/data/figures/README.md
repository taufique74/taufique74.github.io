# Figure data

Precomputed data for interactive components. Everything here is generated by a
script in `scripts/figures/` and committed — nothing is computed at request time.
That keeps the site deployable to any static host.

## Regenerating

```bash
conda run -n mech_interp python scripts/figures/gpt2_induction_attention.py
```

Each script writes exactly one JSON file here and prints a summary you can eyeball
against the paper claim it is meant to reproduce.

## Budget

Keep a single figure under ~200 KB. Attention patterns are `O(n²)` per head, so
cost is driven by sequence length, not model size:

| tokens | per head | 6 heads (3 dp)     |
| ------ | -------- | ------------------ |
| 31     | 961      | ~32 KB             |
| 64     | 4,096    | ~135 KB            |
| 128    | 16,384   | ~540 KB — split it |

Round to 3 decimals. A heatmap cannot show more precision than that, and it cuts
the payload roughly in half versus full float repr.

## Contract: attention patterns

Consumed by `src/components/interactive/AttentionPattern.astro`.

```jsonc
{
  "model": "gpt2-small",
  "tokens": ["<|endoftext|>", " token", ...],  // length n, display order
  "nTokens": 31,
  "prompt": { "kind": "repeated-random", "seqLen": 15, "description": "..." },
  "inductionOffset": 14,                        // optional, for annotation
  "heads": [
    {
      "layer": 5,
      "head": 5,
      "label": "L5H5",
      "inductionScore": 0.8282,                 // optional
      "values": [[0.9, 0.0, ...], ...]          // [query][key], n x n, rows sum to 1
    }
  ],
  "baseline": { "meanInductionScore": 0.117, "nHeadsTotal": 144 }
}
```

`values` is row-stochastic and causally masked — entries above the diagonal are 0.
The component does not verify this; it just renders what it is given.
